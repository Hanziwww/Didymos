# Paper materials: Didymos 1.0 (the `MUC32_main` twin model)

**Start with `results_current.md`.** It gives the current state of every experiment, improved versions first, with
pointers to the tables.

**Conventions:**
- **Protocol:** `docs/p1_paper_protocol.md`. New experiments enter as dated amendments, written before they run.
- **Splits and intervals:** results are on the held-out split, with 95% intervals by a bootstrap over stays.
- **Aggregates only:** the materials hold no individual stay or trajectory.
- **Data stays out of the repository** (`.gitignore`): the credentialed data, the runs and the per-anchor
  predictions. The aggregate JSON files behind the tables are under `runs/paper/` on the GPU host, with a
  git-ignored local copy under `runs/paper/`; the toolkit's validation aggregates are under `runs/toolkit/v1`-`v5`
  (the RTX 5090 host, with a local copy of the JSON files).
